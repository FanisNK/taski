# Taski

Приложение для удобного планирования и отслеживания повседневных задач. Позволяет создавать, редактировать, отмечать выполненные задачи и управлять своим списком дел через REST API.

## Стек технологий
* **Python**
* **Django**
* **Django REST Framework (DRF)**
* **SQLite / PostgreSQL**

## Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/FanisNK/taski.git](https://github.com/FanisNK/taski.git)
Создайте и активируйте виртуальное окружение:

Bash
python -m venv venv
source venv/bin/activate  # для Mac/Linux
source venv/Scripts/activate  # для Windows
Установите зависимости:

Bash
pip install -r requirements.txt
Выполните миграции базы данных:

Bash
python manage.py migrate
Запустите сервер:

Bash
python manage.py runserver
